# Developer Support

## API Updates

For the most recent news and announcements of the XYZ API, please visit the [XYZ API Community](). This is your primary source for official updates and any important information regarding the XYZ API. For detailed technical changes, refer to the [API Changelog]().


## Knowledge Base

For a selection of informative articles, browse the [XYZ API Knowledge Base](). It serves as a good starting place to see if your question has been addressed.

## Community

Join the [XYZ API Community]() to engage in discussions with fellow developers. This is the place to share your experiences, ask for advice on best practices, and participate in ongoing conversations. Keep an eye out for additional announcements and community insights shared here.

## Technical Assistance 

If the API is not working as expected, open a [Cisco Technical Assistance Center (TAC) case](https://mycase.cloudapps.cisco.com/case) via Cisco Support Case Manager. 

To contact TAC, use the following options:

* [Cisco Support Case Manager](https://mycase.cloudapps.cisco.com/)
* [Cisco Worldwide Support Contacts](https://www.cisco.com/c/en/us/support/web/tsd-cisco-worldwide-contacts.html)
* Webex: `tac.connect@webex.bot`
* First Time? [Start here](http://cs.co/first-time)

## Consulting

For consulting, contact a [Cisco Developer Partner](https://www.cisco.com/c/en/us/partners/connect-with-a-partner.html) or your Cisco Sales Team for professional service options.
